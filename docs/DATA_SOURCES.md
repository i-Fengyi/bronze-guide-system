# 数据来源与知识库说明

本项目已切换为中国国家博物馆青铜器主题，旧 The Metropolitan Museum of Art 图册不再参与识别或知识检索。

## 图像数据

- `data/raw_dataset/`：8 类器型分类训练数据：鼎、簋、爵、觚、尊、卣、盉、壶。
- `data/exhibit_gallery/`：8 件重点文物的候选图库，每件文物 20 张图片，用于第二阶段相似度匹配。

## 文字资料

知识条目保存在 `data/exhibits.json` 和 `data/vessel_types.json`，优先依据中国国家博物馆官方藏品页面整理。每条记录保留来源页面 URL，并在回答中作为 RAG 资料来源展示。

## 研究边界

当前系统用于课程设计中的图像分类、图像相似度检索和资料辅助讲解，不对文物真伪、年代或考古结论作鉴定。
